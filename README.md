# Backend Development

This repository documents my backend development journey using **Node.js**, **Express.js**, **MongoDB**, and related technologies. Each project builds upon the previous one, following a structured learning path from backend fundamentals to production-ready applications.

## 📂 Projects

- ✅ 01 - Notes API
  - CRUD operations using Express.js and MongoDB

- ✅ 02 - Cloud Storage API
  - React + Node.js image upload using Multer and ImageKit

- ✅ 03 - Backend Authentication
  - User registration, login, password hashing with bcrypt, JWT authentication, and protected routes

- ✅ 04 - Notes API with Authentication
  - Secure Notes API with JWT authentication, user-specific notes, and protected CRUD operations

- ⏳ 05 - Spotify Backend
  - Spotify-inspired backend with authentication, playlists, and music APIs

- ⏳ 06 - Testing with Jest & Supertest

- ⏳ 07 - API Validation
